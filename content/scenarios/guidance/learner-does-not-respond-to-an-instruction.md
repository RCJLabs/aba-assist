id: learner-does-not-respond-to-an-instruction
kind: guidance
title: You give an instruction and the learner does not respond at all
situation: >-
  You present an instruction from a program the learner has been working on. The
  learner looks away, stays still, or keeps doing what they were doing. Nothing unsafe is
  happening. The program has a written prompting procedure.
setting: clinic
audience: [RBT, BCaBA, BCBA]
riskFlags: []
steps:
  - text: Wait the interval your program specifies before doing anything else.
    rationale: >-
      Many programs build in a response window on purpose. Prompting too early teaches the
      learner to wait for help.
  - text: Deliver the next prompt level exactly as the prompting procedure is written.
    rationale: >-
      The prompt hierarchy was chosen for this learner. Skipping levels or adding a
      different kind of help changes the teaching.
  - text: Reinforce the response the way the program says, including prompted responses if the program says to.
    rationale: >-
      Whether prompted responses earn reinforcement is a program decision, and it changes
      what the data mean.
  - text: Record the trial as prompted or independent, at the level actually used.
    rationale: >-
      Prompt-level data are how the supervisor decides when to fade. Recording an
      independent response that was prompted hides the learner's real progress.
  - text: Check whether the learner was attending before the instruction, and note it if not.
    rationale: >-
      An instruction given to a learner who was not attending is a different event from
      one that was attended and not answered.
whatNotToDo:
  - >-
    Do not repeat the instruction several times in a row. Each repetition is a new
    trial, and it teaches the learner that the first one does not count.
  - >-
    Do not invent a prompt that is not in the hierarchy, however natural it feels.
  - >-
    Do not score the trial as correct because the learner eventually got there with
    help.
whenToEscalate:
  - >-
    Tell your supervisor if the learner is not responding across several programs or
    several sessions, or if the lack of response is new.
  - >-
    Ask before the next session if you are unsure what the response window or the
    prompt levels are for this program.

The most common mistake here is the most understandable one: repeating yourself. A
repeated instruction feels like patience. In the data it is several trials, and in the
learner's experience it is a lesson that the first instruction is optional.
