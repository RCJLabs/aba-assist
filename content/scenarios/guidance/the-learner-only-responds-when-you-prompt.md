id: the-learner-only-responds-when-you-prompt
kind: guidance
title: The learner only gets it right when you help
situation: >-
  The learner performs the skill reliably, but only when you prompt. Take the prompt
  away and the response does not come. The data look good and the skill is not really
  there.
setting: clinic
audience: [RBT, BCaBA, BCBA]
riskFlags: []
steps:
  - text: >-
      Check the prompt-fading procedure the programme specifies, and whether you have been
      running it.
    rationale: >-
      Most programmes already name how prompts come off. Prompt dependence is often a fading
      step that quietly stopped being run.
  - text: >-
      Watch your own timing. Prompting before the learner has had a chance to respond is the
      most common way this happens.
    rationale: >-
      A prompt delivered early every time makes the prompt the thing the learner waits for,
      and waiting is reinforced.
  - text: >-
      Run the fading step as written — the delay, the reduced help, the changed materials —
      rather than simply removing the prompt.
    rationale: >-
      Removing help abruptly usually produces errors, and errors here teach the wrong thing
      about what the instruction means.
  - text: >-
      Record prompted and unprompted responses separately if the data sheet allows it.
    rationale: >-
      A percentage that mixes helped and unhelped responses hides exactly the problem you
      are trying to see.
  - text: >-
      Tell your supervisor what you are seeing, with the numbers.
    rationale: >-
      Changing a fading procedure is a clinical decision. Noticing that it is not working is
      yours.
whatNotToDo:
  - >-
    Do not simply stop prompting to see what happens.
  - >-
    Do not change the fading procedure yourself.
  - >-
    Do not score a prompted response as independent.
whenToEscalate:
  - >-
    Tell your supervisor if independent responding is not increasing over sessions.
  - >-
    Ask your supervisor if the programme does not specify how prompts should be faded.
