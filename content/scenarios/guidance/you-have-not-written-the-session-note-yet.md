title: The session note has not been written and time has passed
situation: >-
  A session finished and the note did not get written — you ran to the next appointment,
  the day ended, or you simply forgot. It is now hours or days later and the note is
  still outstanding.
setting: any
audience: [RBT, BCaBA, BCBA]
riskFlags: []
steps:
  - text: >-
      Write it now rather than later, and write it from what you actually remember and
      recorded.
    rationale: >-
      Every hour makes the note less accurate. The version written today is better than the
      more confident one written on Friday.
  - text: >-
      Date it honestly. Record when the session happened and when you wrote it up.
    rationale: >-
      A note written late and dated late is a late note. A note written late and dated as
      though it were not is a falsified record.
  - text: >-
      Say what you do not remember rather than filling it in.
    rationale: >-
      A gap is a fact about the record. An invented detail is indistinguishable from an
      observed one once it is written down.
  - text: >-
      Use the data sheet as the source, not your memory of how it went.
    rationale: >-
      What was recorded at the time is the evidence. Recollection after the fact is
      reconstruction, and it drifts towards what you expected.
  - text: >-
      Tell your supervisor if notes are regularly going unwritten.
    rationale: >-
      A pattern of late notes is usually a scheduling problem rather than a discipline
      problem, and it has a fix.
whatNotToDo:
  - >-
    Do not write the note from what usually happens in that session.
  - >-
    Do not date it as though it were written on the day.
  - >-
    Do not leave the note unwritten because it is now late.
whenToEscalate:
  - >-
    Tell your supervisor if you cannot complete a note accurately.
  - >-
    Tell your supervisor the same day if a note is outstanding past whatever deadline your
    employer or funder sets.
