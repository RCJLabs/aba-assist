id: learner-uses-the-break-card-constantly
kind: guidance
title: The learner asks for a break every few minutes
situation: >-
  The learner was recently taught to ask for a break instead of protesting, and it has
  worked: protests are down. But now they ask for a break constantly, and very little
  work is getting done. You are wondering whether to start refusing some requests.
setting: school
audience: [RBT, BCaBA, BCBA]
riskFlags: []
steps:
  - text: Honor the break request every time the plan says to. Early in functional communication training that is usually every time.
    rationale: >-
      The new request works only because it is reliable. Refusing it before the plan
      says to teaches the learner that asking does not work, and the old behavior comes
      back.
  - text: Deliver the break exactly as specified — its length, what is available during it, and how it ends.
    rationale: >-
      A break that drifts longer or richer than written changes the contingency.
  - text: Record every request and every break, with the timing the plan asks for.
    rationale: >-
      A high rate of requests is expected at this stage. The data are what tell the
      supervisor when to begin thinning.
  - text: Tell the supervisor what you are seeing, and ask whether the plan is ready for the next step.
    rationale: >-
      Adding delays, a limited number of break cards, or a work requirement before a
      break are all later steps of the same procedure, and they are the analyst's call.
whatNotToDo:
  - >-
    Do not start refusing or delaying requests on your own initiative.
  - >-
    Do not remove the break card because it is being "overused."
  - >-
    Do not treat the high rate as the program failing; it is the program working.
whenToEscalate:
  - >-
    Bring the data to your supervisor promptly so thinning can be planned; sooner if
    the learner is missing most of the session.
