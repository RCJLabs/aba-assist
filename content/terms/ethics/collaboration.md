term: Collaboration
aliases:
  [interprofessional collaboration, caregiver collaboration, working with other professionals]
category: ethics
definition:
  technical: >-
    Working with caregivers, teachers, medical providers and other professionals in the
    client's life — sharing information with consent, coordinating goals, and
    respecting other disciplines' expertise — so that services are consistent and the
    client is not caught between conflicting plans. The ethics code requires it and it
    is a distinct skill, not a byproduct of good intentions.
  plain: >-
    Working together with families, teachers and doctors. The client then gets one
    plan that everyone follows, not several that clash.
  gloss: Working with families and other professionals on shared goals
examples:
  - text: >-
      An analyst and a speech-language pathologist agree on which communication system
      to use so the learner is not taught two at once.
    setting: any
nonExamples:
  - text: >-
      Running a program at the clinic without telling the school, which is running a
      different one for the same behavior.
