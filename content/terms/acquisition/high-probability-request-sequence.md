id: high-probability-request-sequence
term: High-Probability Request Sequence
aliases: [high-p sequence, behavioral momentum procedure, high-p request sequence]
category: acquisition
definition:
  technical: >-
    An antecedent procedure in which several requests the learner is very likely to
    follow are delivered in quick succession, each reinforced, immediately before a
    request the learner is unlikely to follow. The run of reinforced compliance carries
    over into the low-probability request. It is an application of behavioral momentum.
  plain: >-
    Ask for a few easy things the learner will do, praise each one, then ask for the
    hard thing right away. The easy wins carry over.
  gloss: Easy requests in a row, then the hard one
examples:
  - text: >-
      "High five! Touch your nose! Clap!" — praise each — then "Time to put the toys away."
    setting: home
  - text: >-
      "Give me five. Now a thumbs up. Now a high ten." — praise after each — "Now open your
      book to page four."
    setting: school
nonExamples:
  - text: >-
      Letting the learner play after they clean up. Using a preferred activity as a
      reward afterward is the Premack principle.
    setting: home
