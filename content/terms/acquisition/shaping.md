id: shaping
term: Shaping
aliases: [successive approximations, differential reinforcement of successive approximations]
category: acquisition
definition:
  technical: >-
    Reinforcing successively closer approximations to a target response while no longer
    reinforcing earlier ones, so that a single response gradually changes form, force,
    duration, or accuracy until it matches the goal. It builds behavior that is not yet in
    the learner's repertoire at all.
  plain: >-
    Rewarding tries that are a bit closer to the goal, then asking for a bit more. It
    builds something the person cannot do yet by improving one response over time.
  gloss: Rewarding closer and closer tries at one response
examples:
  - text: >-
      A learner who makes any sound toward a word is reinforced at first, then only for
      sounds nearer the word, then only for the word.
    setting: clinic
  - text: Tolerating a haircut is built from sitting near the chair, then in it, then briefly.
    setting: community
nonExamples:
  - text: >-
      Linking separate steps of a task into a routine, which is chaining rather than
      refining one response.
    setting: home
  - text: >-
      Reinforcing the finished skill only, and waiting for it to appear on its own. Without
      reinforcing approximations there is no shaping.
    setting: any
contrastWith: [chaining]

Shaping requires judgement about when to raise the bar. Moving too fast loses the
behavior; moving too slowly makes the old approximation the new ceiling. Where that line
sits for a given learner is a clinical decision.
