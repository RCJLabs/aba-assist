term: Public Posting
aliases: [posting, feedback board, leaderboard]
category: supervision
definition:
  technical: >-
    Displaying performance data where the people whose performance it is can see it, as a
    feedback procedure. The display is the intervention: no consequence is added and no
    instruction is given, and performance typically improves because the data are visible
    and current rather than because anything was promised for them.
  plain: >-
    Put the numbers up on a board where the team can see them. Seeing how you did, soon
    after you did it, is often enough to change how you do it next time.
  gloss: Showing people their own performance data where they can see it
examples:
  - text: >-
      A supervisor posts each week's treatment-integrity percentage by staff code on the
      team board. Integrity rises without any change to training or incentives.
    setting: clinic
    why: The feedback is the procedure; nothing else about the contingencies changed.
  - text: >-
      A coach posts the count of correctly executed plays after each practice. Execution
      improves across the squad.
    setting: community
    why: This is the arrangement the sport-performance literature demonstrated it with.
nonExamples:
  - text: >-
      Posting each supervisee's name beside a ranking framed as who is failing. That is a
      different procedure with different effects, and it raises ethical problems this one
      does not.
    setting: clinic
  - text: >-
      A supervisor telling one staff member privately how they did. That is individual
      feedback — useful, but not this procedure, and it does not make the data current and
      visible to the group.
    setting: clinic

Cheap, fast and well supported, which is why it turns up throughout performance management
in behavior-analytic organizations. It is also the procedure most easily done badly: what
gets posted is a choice, and posting the wrong measure will improve the wrong thing.

Whose data go up is an ethical question as much as a technical one. Posting by code rather
than by name, posting a measure people can actually influence, and agreeing the display
with the people in it are the differences between feedback and a public reprimand.
