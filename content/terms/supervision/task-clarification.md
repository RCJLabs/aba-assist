term: Task Clarification
category: supervision
definition:
  technical: >-
    An antecedent intervention for staff performance that restates precisely what is
    expected, in observable terms, and confirms that everybody involved understands the
    same thing. It is the correct first response when people describe the same task
    differently, because feedback against an unclear standard produces inconsistent
    correction rather than consistent performance.
  plain: >-
    Saying exactly what the job is, so everyone means the same thing. Do this first when
    people describe the task differently.
  gloss: Restating precisely what staff are expected to do
examples:
  - text: >-
      Four staff describe the same data step differently, so the step is rewritten as
      two observable actions and confirmed with each of them.
    setting: clinic
nonExamples:
  - text: >-
      Giving each of the four individual feedback against a step none of them reads the
      same way.
    setting: clinic
