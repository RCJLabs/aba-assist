id: multiple-baseline-design
term: Multiple Baseline Design
aliases: [multiple-probe design, staggered baseline]
category: research-design
definition:
  technical: >-
    A single-case design in which baselines are established for two or more behaviors,
    settings or people, and treatment is introduced to each in a staggered sequence.
    Control is shown when each baseline changes only when treatment reaches it. The
    multiple-probe variation measures untreated baselines intermittently rather than
    continuously. It suits behavior that cannot or should not be reversed.
  plain: >-
    Start the same treatment at different times for different behaviors, places, or
    people. If each one changes only when its treatment starts, the treatment is the
    cause.
  gloss: Treatment introduced in a staggered order across baselines
examples:
  - text: >-
      Greetings are taught first at home, then at school, then at the clinic. Each
      setting improves only after teaching begins there.
    setting: any
nonExamples:
  - text: >-
      Withdrawing and reintroducing a treatment with one learner. That is a reversal.
    setting: any
