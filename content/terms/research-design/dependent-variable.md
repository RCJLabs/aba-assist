id: dependent-variable
term: Dependent Variable
aliases: [DV, target behavior]
abbreviation: DV
category: research-design
definition:
  technical: >-
    The behavior that is measured to see whether it changes when the independent
    variable is manipulated. In applied work it is the socially important target
    behavior, defined operationally so that it can be recorded consistently.
  plain: >-
    The behavior you measure to see if the treatment made a difference.
  gloss: The behavior being measured
examples:
  - text: >-
      In a program to reduce elopement from the classroom, the number of times the
      student leaves without permission is the dependent variable.
    setting: school
nonExamples:
  - text: >-
      The token system used to reduce that leaving. The thing you change on purpose is
      the independent variable.
    setting: school
