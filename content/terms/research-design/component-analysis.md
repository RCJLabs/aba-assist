id: component-analysis
term: Component Analysis
aliases: [dismantling study]
category: research-design
definition:
  technical: >-
    An experimental comparison that adds or removes parts of a treatment package to
    determine which parts are responsible for its effect. It answers a question services
    rarely ask: packages accumulate components nobody has tested, and an inert component
    costs staff time every session for as long as it stays in the plan.
  plain: >-
    Testing the parts of a treatment package one at a time, to find out which parts are
    doing the work.
  gloss: Testing which parts of a treatment package produce its effect
examples:
  - text: >-
      A package with four components is run with the visual schedule removed, and
      responding is unchanged, so the schedule is dropped.
    setting: clinic
nonExamples:
  - text: >-
      Introducing four components at once and concluding that all four were necessary
      because the package worked.
    setting: any
