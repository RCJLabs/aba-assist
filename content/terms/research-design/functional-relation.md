id: functional-relation
term: Functional Relation
aliases: [functional relationship]
category: research-design
definition:
  technical: >-
    A demonstrated dependency between a change in the environment and a change in
    behavior: the behavior reliably changes when, and only when, a specific variable is
    manipulated, and the effect is reproduced. It is what an experiment establishes and
    what "the intervention worked" properly means.
  plain: >-
    Proof that one thing changes another. The behavior changes when you change the
    variable, and it does it again when you repeat the change.
  gloss: A shown cause-and-effect link between environment and behavior
examples:
  - text: >-
      Talking-out drops each time the teacher starts giving attention for hand raising,
      and rises each time she stops. The relation between attention and hand raising is
      functional.
    setting: school
nonExamples:
  - text: >-
      Behavior improved during the same month a new program started. Without a return
      to baseline or a staggered comparison, that is a correlation, not a demonstrated
      relation.
    setting: any
