id: parametric-analysis
term: Parametric Analysis
aliases: [dose-response analysis]
category: research-design
definition:
  technical: >-
    An experimental comparison that varies the value of one dimension of a procedure —
    the duration of reinforcer access, the delay, the ratio requirement, the session
    length — while holding the procedure itself constant, to find how the effect changes
    with that value. It distinguishes a procedure that does not work from one being run
    at the wrong setting.
  plain: >-
    Changing how much of something a procedure uses — how long, how often, how many — to
    find the amount that works.
  gloss: Varying the amount of one element to find what works best
examples:
  - text: >-
      Thirty, sixty and one hundred and twenty seconds of access are compared as
      reinforcement for the same response.
    setting: clinic
nonExamples:
  - text: >-
      Comparing a token system with a praise-only condition, which contrasts two
      procedures rather than two values of one.
    setting: any
