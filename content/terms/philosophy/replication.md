id: replication
term: Replication
aliases: [direct replication, systematic replication]
category: philosophy
definition:
  technical: >-
    Repeating an experiment or an effect to see whether it holds. Direct replication
    repeats the same procedure with the same conditions; systematic replication varies
    something on purpose to test how far the finding extends. Within a single-case
    design, each return to a condition that reproduces the earlier result is a
    replication too.
  plain: >-
    Doing it again to see if you get the same result. Repeating an effect is what makes
    it believable.
  gloss: Repeating a result to show it is real
examples:
  - text: >-
      In an A-B-A-B design, the second B phase reproduces the first improvement, which
      is a replication of the effect within one learner.
    setting: any
nonExamples:
  - text: >-
      A single dramatic improvement in one phase with no attempt to reproduce it. It may
      be real, but nothing yet shows that it was the treatment.
    setting: any
