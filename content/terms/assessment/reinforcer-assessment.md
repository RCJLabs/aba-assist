id: reinforcer-assessment
term: Reinforcer Assessment
category: assessment
definition:
  technical: >-
    A direct test of whether an item actually functions as a reinforcer, by delivering
    it contingent on a response and measuring whether the response increases. It is the
    step after a preference assessment: preference predicts reinforcement but does not
    guarantee it, and the only proof is an effect on behavior.
  plain: >-
    Checking whether a preferred item really makes behavior go up when it is used as a
    reward. Liking something is not the same as working for it.
  gloss: Testing whether a preferred item actually reinforces
examples:
  - text: >-
      The top-ranked item is delivered for each completed task and the rate of task
      completion is compared with sessions using the second-ranked item.
    setting: clinic
nonExamples:
  - text: >-
      Ranking items by how often the learner chose them. That is a preference
      assessment; nothing was made contingent on behavior.
    setting: clinic
