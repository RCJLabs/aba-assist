id: phase-change-line
term: Phase Change Line
aliases: [condition change line, phase line]
category: graphing
definition:
  technical: >-
    A vertical line on a graph marking the point at which a condition changed — from
    baseline to treatment, or between two treatments. Data points are never connected
    across it, so the reader can see each condition as its own set and compare them.
    Each phase is labeled above the line.
  plain: >-
    The vertical line on a graph where the plan changed. Dots are not joined across it,
    so each phase stands on its own.
  gloss: A vertical line marking a change in conditions
examples:
  - text: >-
      A dashed line between session 10 and session 11, labeled "Baseline" on the left
      and "DRA" on the right.
    setting: any
nonExamples:
  - text: >-
      A horizontal line showing the goal level. That is an aim or criterion line, not a
      phase change.
    setting: any
