id: fixed-interval-schedule
term: Fixed-Interval Schedule
aliases: [FI schedule, FI]
abbreviation: FI
category: principles
definition:
  technical: >-
    A schedule in which the first response after a set amount of time has passed is
    reinforced — FI 2 minutes means that after two minutes, the next response earns
    reinforcement. Responses before the interval ends do nothing. It typically produces
    little responding early in the interval and an increase as the end approaches.
  plain: >-
    After a set amount of time, the next response is rewarded. Responses before the
    time is up do nothing, so behavior tends to pick up as the time nears.
  gloss: First response after a fixed time is reinforced
examples:
  - text: >-
      A teacher checks on a student every five minutes and praises on-task work if she
      sees it then. Work picks up shortly before each check.
    setting: school
nonExamples:
  - text: >-
      Praise for every fifth completed problem regardless of time. That is a ratio
      schedule.
    setting: school
contrastWith: [variable-interval-schedule, fixed-ratio-schedule]
