id: stimulus-class
term: Stimulus Class
aliases: [formal stimulus class, functional stimulus class, feature stimulus class]
category: principles
definition:
  technical: >-
    A group of stimuli that share something and so affect behavior in the same way. They
    may share physical features (all red things), a temporal relation to behavior (all
    events that follow a response), or a function (all things that signal a break is
    available), and membership can differ for different learners.
  plain: >-
    A group of things that count as the same for a learner, because they look alike or
    do the same job.
  gloss: Stimuli grouped by shared features or shared function
examples:
  - text: >-
      Pictures of many different dogs, all of which occasion the word "dog," form a
      stimulus class for that learner.
    setting: any
nonExamples:
  - text: >-
      A single flash card. One stimulus is not a class; the class is the set of things
      that work the same way.
    setting: clinic
