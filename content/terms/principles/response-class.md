id: response-class
term: Response Class
aliases: [functional response class, operant class]
category: principles
definition:
  technical: >-
    A group of responses that differ in form but produce the same effect on the
    environment, and so are strengthened or weakened together by the same consequences.
    The operant is defined by function, not topography: hitting, kicking and screaming
    can all be one class if all of them end a demand.
  plain: >-
    A set of different-looking behaviors that all do the same job. If they get the same
    result, they rise and fall together.
  gloss: Different responses that share one function
examples:
  - text: >-
      Asking, pointing, and pulling an adult's sleeve all get a toy from the shelf. They
      form one response class maintained by access to the toy.
    setting: home
nonExamples:
  - text: >-
      Two behaviors that look identical but serve different purposes, such as clapping
      to a song and clapping to get attention. Same form, different classes.
    setting: school
