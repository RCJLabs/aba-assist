term: Extinction
aliases: [EXT, extinction burst, planned ignoring]
category: principles
definition:
  technical: >-
    Discontinuing the reinforcement that has maintained a response, with the result that
    the response decreases over time. The procedure is specific to the maintaining
    consequence, so extinction for attention-maintained behavior differs from extinction
    for escape-maintained behavior. A temporary increase in rate, intensity, or
    variability at the start is common.
  plain: >-
    A behavior stops working, so over time the person does it less. What you withhold
    depends on what was keeping the behavior going. The behavior often gets worse before
    it gets better.
  gloss: The behavior stops working, so it fades over time
examples:
  - text: >-
      An elevator button that no longer lights up. A person presses it several more times,
      presses harder, then stops using it.
    setting: community
    why: The consequence that maintained pressing is gone, including the burst.
  - text: >-
      A written plan directs staff not to end a task when a learner whines, because the
      task ending is what has maintained whining.
    setting: school
nonExamples:
  - text: >-
      Ignoring a behavior that is maintained by escape from work. Ignoring does not
      withhold escape, so this is not extinction for that function.
    setting: clinic
    why: Extinction must target the actual maintaining consequence.
  - text: >-
      Withholding reinforcement for a behavior nobody has assessed. Without knowing the
      function you cannot know what to withhold.

"Extinction" and "planned ignoring" are not synonyms, and treating them as such is a
common and consequential error. Ignoring only functions as extinction when attention was
the maintaining consequence.

Extinction procedures are written by the supervising analyst. If a plan appears to call
for extinction and the behavior escalates in a way that worries you, that is a
conversation to have with your supervisor the same day, not a judgment call to make
alone.
